# Pet Pal Website

This is the official website for Pet Pal iOS app.

## GitHub Pages Deployment

This website is configured for GitHub Pages deployment from the `/docs` folder.

### Setup Instructions:

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select the branch (usually `main` or `master`)
4. Select `/docs` as the folder
5. Click "Save"

Your website will be available at: `https://tomsobkow-wq.github.io/test-iOS/`

## Local Development

To view the website locally:
1. Open `index.html` in your web browser
2. Or use a local server like `python -m http.server 8000` in the docs directory
